# Dam Break Inundation Modelling System

## Problem Statement

Development of a software-based framework for estimating flood
inundation caused by dam break or river blockage scenarios.

## Objective

To provide a simple software system that accepts hydrological,
Digital Elevation Model and dam-break parameters and generates
flood inundation estimates and visualization.
